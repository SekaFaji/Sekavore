# Sekavore

A browser-playable incremental mining game. Progress is saved locally in your browser.

## Run locally
```bash
python3 -m http.server 8080
```
Open http://localhost:8080.

## Tests
```bash
npm test
```

## Latest update (v0.22)
Compact Upgrades, Craft and Sell UI with resource previews and ore lock controls.
Mining now regenerates rock waves only after a full clear, floor progress is capped at its quota, and Auto-Floor can resume through previously cleared floors. Combat economy, saves, and artwork remain unchanged.

## v0.26

Statistics now show compact grouped Pickaxe, Bomb, Drone and Misc tables, and Currencies has compact tabs for ores, bars and funds. These pages show the current tracked game state and introduce no new gameplay content. The previous Bomb control behavior is preserved.

## Permanent Relics
Relic chests grant supported permanent bonuses. Current Common–Legendary effects use a limited research reward pool; advanced effects, exact tier odds and original thresholds remain unverified.

## v0.30
The Menu Hub now shows Obelisk unlock requirements, distinguishes future previews from playable systems, and provides feedback when a locked icon is pressed. Gameplay and saves are unchanged.
