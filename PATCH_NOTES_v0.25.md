# Sekavore v0.25 — Bomb controls

- FIRE spends one charge of the selected Basic Bomb. Holding FIRE repeats at the 1.25-second manual-fire cadence.
- FIRE ALL spends all charges of the selected Basic Bomb and applies their combined damage to the current visible rock wave.
- Auto-Bomber is a separate, locked Skill Tree system; it is not enabled by default or mixed with drones.
- Recharge continues using the existing 9-second interval and charge cap. The progress bar, next charge, and time to full reflect that state.
- No bomb types, shop content, artwork, mining economy, or save schema were added.

The existing nine-second balance is provisional. Exact current-release recharge formulas are not yet verified.
