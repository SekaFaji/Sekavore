# Sekavore v0.26 — Statistics and Currencies UI

- Compact four-section Stats Page 1 (Pickaxe, Bomb, Drone and Misc), using gameplay values.
- Stats Page 2 shows tracked progression/economy; Page 3 shows recorded activity.

- New stylesheet included in GitHub Pages publication, checked by existing asset dependency test.
