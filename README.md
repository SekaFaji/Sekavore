# Sekavore

A browser-playable incremental mining game. Progress is saved locally in your browser.

## Run locally
```bash
python3 -m http.server 8080
```
Open http://localhost:8080.

## Tests
```bash
npm test
```

## Latest update (v0.22)
Compact Upgrades, Craft and Sell UI with resource previews and ore lock controls.
Mining now regenerates rock waves only after a full clear, floor progress is capped at its quota, and Auto-Floor can resume through previously cleared floors. Combat economy, saves, and artwork remain unchanged.
