# Sekavore v0.28 — Permanent Relic Chests

- Open 1 or Open All (up to 500 per action) with owned relic display grouped by rarity.
- Adds functional permanent bonuses for damage, selling, experience, bombs, recharge, capacity and Prestige Points.
- Rarity/weights reflect only currently implemented Common–Legendary rewards; advanced rarity effects are deferred.
- Preserves existing save version, chest progress, consumables, menu positions and art.
- New Pages asset regression tests ensure the new module and CSS are bundled.

**Research caveat:** Relic names/bonuses based on historically documented reward tables, not recovered executable APK formulas. Odds are a reweighted subset of eligible effects.
