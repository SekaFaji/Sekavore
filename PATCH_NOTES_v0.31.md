# Sekavore v0.31 — Floor Waves and Travel UI

- Floor unlock progress now counts whole cleared ore waves, not individual rocks.
- Retains the existing provisional 1.25-second wave respawn delay and current wave population.
- Uses a provisional 150-wave early-floor target based on player discussion; exact reference scaling remains unverified.
- Displays current floor between travel controls; quick previous-floor and floor-selector actions remain available.
- Migrates old rock-based progress proportionally and preserves already reached floors.
- Workshop and Challenges text clarifies supported functions without inventing rewards.
- No artwork, mining damage, ore yields, save-version or unrelated systems changed.
